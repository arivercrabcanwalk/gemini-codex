# Track B 实现状态

本目录是本地合成工程验收原型。7 条输入轨迹和 37 个固定检查点的重放通过，只说明这些输入的工程行为与固定检查点一致。它们不是科研实验、训练结果、算法质量评价或服务器复现结果。现有输入和期望文件在本次修复中保持原字节。

已实现：毫秒事件钟、物理模式与 epoch、准确有理数四桶账本、原子候选提交、固定工单服务量及认领、任务身份和完成核查。相同站点和塔位的多个巡检任务必须在 stop 中显式写 `task_id`；唯一任务保留原先省略该字段的兼容形式。同一任务或工单在一份见证中重复出现会被拒绝。

策略回调仅能选择接口提供的 `STEP(station, slot, target_or_RETURN)` 物理动作。策略不能选择等待、补全算法或自造补全路线。没有可用物理动作时，执行器自行返回 `NO_EXECUTOR_ACTION`，不会调用策略。共享补全器只搜索最多 6 个待办服务的全部顺序和分趟，不插入可选悬停；额度触顶单列 `COMPLETION_LIMIT_EXCEEDED`，不是不可行证明。该有界搜索不代表完整业务域的精确补全算法。

计时接口会把实测 snapshot 到 ready 的墙钟向上取整为毫秒，并先推进期间的物理及外生事件，再执行 CAS；旧 epoch 或已起飞的无人机会被拒绝。`wall_decision_to_commit_ms` 另含提交本身的测量开销。7 条固定轨迹中的提案时刻由输入提供，不能当作实测策略推理速度；独立 B6 回调仅是工程计时诊断。500ms 字段是测量结果，不是所有输入规模的速度保证。

`run_track_b_acceptance.py --blind-only` 只写实际日志，不读取期望文件；原 `--write-expected` 自证通路已经移除。保留正常比较模式及独立 `independent_comparator.py` CLI。输出路径不得覆盖输入、期望或彼此。

比较器要求实际与期望的轨迹集合完全一致，并对每条实际事件检查四桶长度、非负与守恒、时间、计数、ledger、epoch/模式、班末合规，然后比较固定检查点。它是独立的导出状态检查程序，不是独立物理仿真器。只有 37 个检查点不能单独证明所有中间物理事件完整；期望文件的独立推导来源也未由本包证明。

尚未实现或验证：学习器、训练权重、真实 RL 策略、完整在线基线竞赛、全业务规模补全、独立物理 oracle、科学收益与统计结论。不得把这些名称或未来接口设计写成已完成方法。
